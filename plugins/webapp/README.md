# Webapp

Agentic web app delivery for a non-technical owner working in plain language.

The plugin bundles six skills:

- `setup` starts a new application;
- `adopt` takes responsibility for an existing live application;
- `next` turns later requests into verified deliveries;
- `migrate` moves existing data deliberately;
- `gaps` identifies one missing operational or product safeguard;
- `graphify` builds a local knowledge graph of the repository.

Both Codex and Claude Code load these skills from this self-contained plugin directory. The root
`skills/` directory mirrors the same files only for users who prefer individual installation with
`npx skills add`.

See the repository [README](../../README.md) for installation commands.
